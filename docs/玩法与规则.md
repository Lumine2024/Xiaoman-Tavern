# 玩法与规则

本页描述当前验收版。数值以运行JSON为准；教程、竞争和同行专属目标各有独立统计，不能混用。

## 从教程到普通经营

首次新建栏位，老酒保通过六屏开场交出钥匙，再陪玩家完成六单首夜。第1、2、4单有完整聚光，第3、5、6单自主操作；自主时撤掉遮暗与输入限制，保留配方和交谈。教学倒计时暂停，但量取／调和仍需玩家停止，允许失误与放弃。首次量取镜头到位后等待「我读完了，开始量取」，此时不倒酒、不扣库存或成本；后续量取按普通流程。

教程打烊后引导补货，允许自由查看商店，最后由玩家主动结束。共享教程完成后，新栏位直接进入普通经营；读现有进度不重播开场。

普通轮次先抽六位对手中的一位，再选五位同行之一，进入D0备货。初始360金、六个基酒家族各600mL，其他液体辅料为零。D0可翻酒谱、采购及升级，转D1不执行隔夜损耗。营业中的等级解锁看连续世界日历，开启新挑战不倒退日期。

每天挂牌一款主推，正常有5–6位基础客流，再由已定义竞争及事件修正。普通随机订单权重为普通1、潮流4、主推12，主推至少三单的保底保留，同款不叠加主推与潮流权重。正常订单不按现有库存筛选、不预留或自动补料；真实配方及后注不足时送客，不扣料、不收入、不推进剧情，也不抽消息。

## 一杯酒的流程

记下要求 → 抽屉选瓶与量取 → 点壶倒入 → 完成第二轮交谈／调前固体 → 调和 → 选杯与冰 → 入杯及后注 → 第三轮交谈／确认特殊要求 → 装饰 → 点铃出品。

量取放大真实量筒，点击画面或空格立即停止，不会到线自动停；读档或重开教程需重新确认首次阅读。摇和／搅拌等在真实判定条停指针，直调自动晃匀，无额外计时判定。后注保持杯子直立，成酒近景显示实际杯、冰、液体、装饰与二维气泡。Esc暂停，Tab手账；减少动画可跳过视觉过程，但不改变经营随机数。

普通经营第二轮透露行情；第三轮保留对手动作与顾客长线。固定教程、缺料送客、鉴定师及特定剧情沿用各自流程。制作失误、等级与漏聊由同一明细汇总，供收入、质量与挑战计分使用；超时／放弃无酒水收入，对手既有豁免只说明，不额外造失误。

## 配方与成本口径

朗姆是白／陈年／高酯三级的同一家族，使用一个库存池；等级决定图像、进价和可制酒，一杯不混用多个等级。迈泰用陈年60mL，僵尸用高酯90mL。莫吉托薄荷只作装饰。船长古典120／20／1mL，双份翻基酒与糖浆；维尔120／20／3mL、三级、无冰无饰。艾露恩当日边车仍橙皮、无冰，减甜预约留次日。精确约束见rulings.json。

实际可选择34种液体，保留36个稳定库存／颜色键以维护朗姆等级及保存结构；不能据此删除等级图片。价格统一从prices.json实时计算，采购按真实包价付款。实际采购批次按FIFO扣成本，损耗按现有分类处理，辅料隔夜损耗、基酒保留。浓缩咖啡只在价格目录预留，不因此新增库存、配方或商品图。

商人赠送库存、未消耗采购、损耗、失败单及鉴定单不计优惠目标；事件费、情报费和还债无折扣。银行家D0／休整／自由经营不计息，逐日防重复发放，D14先结息再冻结；利息和富豪投资不进入经营净收益。

富豪通常要求本轮新增升级原价≥400金、覆盖两类基酒家族；若D0不具备该升级条件，锁定净收益≥2400替代分支，轮中不变。器材现有升级无上限，不能自行新增限制。同行本轮锁定，下一轮重选；专属目标未达标不阻断正常对手胜利推进。成功收束使用交付台词，普通／失败目前仅显示对应标题。

## 十四晚竞争

两项条件必须同时达成。D0准备不计天，D14最后一位正常顾客完成打烊统计后才判定，不提前结算。

| 维奥拉 | 高阶完美≥18 | 至少4款；中等／困难、相关基酒至少二级、零制作失误、完整交谈和要求，无基酒配方不计。 |
| 奥尔加 | 行情命中≥12 | 4次不同行情；六条商店专属预告，生效前采购窗口，每次至少3个正常订单机会。 |

奥尔加须先听预告、备齐实际可制库存并提前挂牌；有效期实际售出才计分。换主推不抹去已完成准备，同一事件跨日仍只算一次机会。该保障不依赖普通顾客50%的消息抽签。

竞争公开目标不等于六位完整营业AI。当前卡恩有价格战、观察／学习、D6上门与D10升级，其他五位保留已接习惯／文本。跟价、错位、拉人可选，D6可换一次；守价加料和囤货的未量化内容仍禁用占位。

获胜后可选未击败对手、休整或自由经营；继承资产、FIFO、等级、声望、顾客记忆、普通事件和连续日历，仅清本轮成绩及对手压力。失败可恢复本轮D0快照重试，或接受失利自由经营；六位全胜后显示终局回顾，可重赛，没有自造额外奖励。

## 市场、消息与手账

37种可计价原料各有涨／跌事件，共74条；22款中等／困难酒有潮流，另有差评、换班，共98条配置。每日最多5件，受互斥、持续和冷却限制。原料D日预告、D+1生效，涨20%持续3晚、跌10%持续2晚；标记provisional的值仍为当前试玩参数。潮流持续3晚，不新增客流或酒价，同款不叠加权重。

相关顾客按50%透露真实消息；普通闲聊包含可能误导的传闻，听见不创造数值事件。价格台词区分预告／生效中／已结束，船长核实读取真实行情。差评按现有延迟生效，可用15%正毛利应对或支付临时60金请鉴定师喝实际制作的主推，正确才解除，无固定500mL扣料。

手账分同行、对手、经营、市场、消息五栏。消息显示实际说话人，可搜索正文或姓名、收藏、多选、分页、删除、清理非收藏及撤销最近一批删除；不显示真假／闲聊类别。旧来源缺失就显示未记录，不根据文本猜来源。整理立即保存，接待中只同步消息字段至起点快照，避免保存半杯库存。
