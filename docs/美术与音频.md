## 按钮、面板与布局

common、dialogue各六态：normal／hover／pressed／hover_pressed／disabled／focus，共12张PNG。save_slot的六个路径直接指向common，仍保留独立theme_types和内容边距。文字由原生控件画，图片不烘焙文字；focus只画边缘（focus_draw_center=false），不能遮住当前态。

按钮九宫格、内容边距在button_skins.json。panel.png用于Esc、手账与存读档，面板九宫格96像素、内容边距40／72／40／40，保留顶部装饰空间。实测两种窗口后再改变边距，尤其是双列存档和长文本。

tools/export_button_skins.gd是显式重建初始模板工具，会覆盖正式PNG；平时换图不要运行。配置共用纹理路径时，导出器按路径去重，使用首次遇到的模板尺寸。

商店右侧每页六件商品，左侧承载挑战、教程采购、行情预告和提前挂牌按钮；底部保留完成备货。采购／批量／应急／赊购与升级原地刷新，保留页码、滚动及有效焦点，不重建整页或重复播放BGM。

## 酒液、杯冰与镜头

drink_colors.json是唯一酒色来源，分liquids的36键与drinks的32键，值为不带井号的八位RRGGBBAA字符串。仅改色值，不改名称或数量；原料和成酒独立定色。AA=00完全不可见，FF不透明，无色酒应结合中性色与透明度调试，不能把液体消失当成清澈。

原占位色未逐项完成美术校色，不把接入颜色表写成校色完成。当前为单色填充，不模拟分层、泡沫或动态混色；瓶图内部颜色不受此表控制。修改透明度需同时检查量筒和暗背景成酒。

drink_display.gd供台面与结算共用；杯液区域、冰块底部间距、内轮廓裁切及装饰偏移在bar_ui.json。大冰／碎冰按贴图尺寸贴底，无冰不绘制冰块。杯口或支点改变后检查七杯型、后注直立、原场景量取／调和、成酒放大和二维气泡；不要用替身弹窗替代现有镜头。暂停、超时、离开及减少动画均需正常恢复。

## 接入新素材

1. Ogg音乐放assets/audio/music，环境放ambience，操作音放sfx；沿用现有音效Ogg亦可，默认制作接口也支持WAV。
2. 在audio.json的files列出真实res://路径，变体列同一个cue；保留稳定ID、group、loop和触发元数据。
3. gain_db调单条增益，settings.defaults调默认四路音量；玩家保存设置优先。循环文件不烘焙起止淡变，自然尾音与循环段分别处理。
4. 建议交付Ogg游戏版、外部保管无损母带，避免在运行目录堆放多份源音频；音乐留出阅读空间，不假设角色配音。

```powershell
godot --headless --path . --script tools/check_audio.gd
```

仅在全部ID正式到齐后使用严格检查；当前18项缺失是如实记录的素材状态。实际试听音量、暂停、场景切换与循环接缝，不将结构检查冒充主观听感。

Web首次点击前受浏览器自动播放限制，点击后AudioContext解锁；中文使用完整Noto Sans SC WOFF2，字体许可见根第三方说明。新增外部素材必须记录许可证，不能只保留下载来源。
