# 构建与部署

工程为Godot 4.5.1纯GDScript，使用同版本**标准版编辑器**和导出模板。两种预设都在export_presets.cfg：Windows Desktop与Web。Godot的.NET版编辑器自身拒绝Web导出，即使工程没有C#，因此建议统一使用标准版。

## 公共资源规则

- 使用all_resources，保障JSON动态引用的立绘、杯瓶、按钮和音频，不可仅按主场景依赖导出。
- docs／tests／tools／exports／编辑器配置有.gdignore，另通过排除过滤器挡住文档、压缩包、脚本工具、日志和缓存；开发索引asset_index_labels.json不进入发行包。
- 25份运行JSON通过resource_data.gd使用ResourceLoader读取并深复制，不依赖FileAccess原始文本读取或Keep File；运行用户文件使用user://。
- 新增FileAccess读取的res://原始文本时，应显式设置Keep File或include_filter，再检查发行包。Web字体OFL.txt已通过include_filter保留。
- 源码内保留图片.import和有效UID，导出缓存由Godot重建；不要把整个.godot或源码带给玩家。

## Windows单EXE

安装Windows导出模板。预设为x86_64、内嵌PCK、关闭额外控制台程序、无代码签名，不导出ANGLE／D3D12额外组件。当前原生GDScript Release无需Godot、.NET或项目专属外置DLL，玩家解压运行EXE即可；操作系统仍需正常可用的图形驱动。验证范围和已知清理提示见验收文档。

从工程根运行：

```powershell
New-Item -ItemType Directory -Force exports/windows | Out-Null
godot --headless --path . --editor --import --quit
godot --headless --path . --export-release 'Windows Desktop' 'exports/windows/小漫特调.exe'
```

也可在Godot「项目→导出」选择Windows Desktop、导出Release。Windows预设排除Web专用字体，沿用系统中文字体。

验包时将EXE复制到源码目录外，工作目录也指向该独立目录，再启动；在源码根目录运行可能误用project.godot，不能据此声称发行包完整。先检查资源加载，再实际试玩；只做headless启动不代表已在干净机器验收全部玩法。

## Web / HTML5

使用web_nothreads_release.zip模板；Compatibility / WebGL 2.0、单线程、无GDExtension、不启用PWA。普通静态HTTP服务无需COOP／COEP或SharedArrayBuffer即可运行。

```powershell
New-Item -ItemType Directory -Force exports/web | Out-Null
godot --headless --path . --export-release 'Web' 'exports/web/index.html'
```

必须将HTML、JS、WASM、PCK、两份音频worklet、图标和启动图整个目录部署，不重命名。Web版使用NotoSansSC.woff2，避免SystemFont不支持浏览器导致中文缺字；附OFL许可证。

此前验收包有12文件、67,013,626字节，ZIP 37,394,775字节（约37.4MB），低于500MB；后续重新导出需重新计算大小和哈希，不能沿用旧数值证明新包。当前资源清理后的构建以实际输出为准。音频已为Ogg、2D图无损压缩，无视频；没有为了限额降低现有画质或音质。

部署步骤：

1. 解压ZIP，将web目录中的全部文件上传到同一静态站点目录，访问index.html。不能直接双击HTML使用file协议。
2. WASM应返回application/wasm；JS、PCK应返回对应文件，不被站点路由回退成首页。子目录部署保持相对路径。
3. 本包运行文件不预压缩为.gz或.br，普通服务器可直接提供；无Unity Decompression Fallback设置。若服务器自行压缩，须正确设置Content-Encoding。
4. 使用支持WebAssembly与WebGL 2.0的现代浏览器。首次点击解锁音频，点击前AudioContext警告属于浏览器策略。

已有Python时，可在导出web目录运行 `python -m http.server 8000 --bind 127.0.0.1`，打开 `http://127.0.0.1:8000/`。Python只是可选本地HTTP服务器，在线玩家不需要安装。

存档在站点IndexedDB，与EXE分开；清理站点数据、无痕窗口或更换来源地址可能影响进度。当前验收为桌面Chromium两种窗口，未做Safari或手机触屏专项。

## 发行包与开源

源码采用根MIT协议。发布EXE／Web时附项目许可证、第三方说明及对应组件许可；Web字体必须保留OFL。根THIRD_PARTY_NOTICES列出Godot引擎及依赖许可入口，不能用项目许可覆盖外部条款。

exports由Git忽略，源码中不提交二进制或ZIP；已有本地发行包保留，适合单独上传Release。对整个交付目录生成SHA256，再将整个目录ZIP压缩，逐文件核对内容并验证CRC与500MB限制。不要把只含index.html的ZIP作为Web版交付。
