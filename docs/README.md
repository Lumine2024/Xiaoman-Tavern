## 本轮整理的去向

| 旧内容类别 | 当前入口 |
| --- | --- |
| 各日期接入记录、implementation、旧竞争／定价说明 | 玩法与规则、开发指南、验收与边界；价格权威保留data/prices.json，金标准保留tests/fixtures。 |
| 教程、UI修改、转场、手账及开场说明 | 玩法与规则、剧情与数据编辑、美术与音频、存档与兼容。 |
| BGM／音效、按钮、酒色、原图README及替换说明 | 美术与音频、图片替换索引、根第三方说明。 |
| Windows导出与Web导出说明 | 构建与部署。 |
| 旧版DOCX、调酒过程TXT、过期讨论及重复裁决生成脚本 | 以较新原稿、当前运行配置与现有导入／定价工具替代，删除旧副本。 |
| 菜单网页计算器 | 移至tools/pricing_calculator.html，读取data/prices.json；仅供基础定价参考。 |
| 10个交付ZIP及已展开音效／UI副本 | 删除；9包内容已展开／接入，另1包为被替换的旧版贴图。需要的运行素材仍在assets。 |

删除前逐份核对交付包与展开文件／运行资源的SHA256；同行立绘包只有说明文字不同，五张立绘均已接入。旧版贴图属于用户要求删除的退役资源。清理也移除旧黑色抠像材质，并让存档按钮直接共用通用纹理。来源批次仍由第三方说明与当前原稿保留。

维护时优先更新现有专题；不要恢复逐日重复文档，不将导出包、日志、缓存或个人目录写入文档。添加新专题前确认docs总文档数仍不超过20。
