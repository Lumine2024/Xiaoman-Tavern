所有表格路径相对工程根；详细替换、酒色、九宫格和音频说明见[美术与音频](美术与音频.md)。角色映射在data/character_art.json，道具映射在data/bar_assets.json，显示几何在data/bar_ui.json。

## 替换前须知

- 同路径覆盖PNG，保留有效.import和UID；换文件名同步运行映射，不按目录顺序绑角色。
- 保持原色、等比和透明留白；杯口、冰、装饰、量筒与壶的轮廓变化需同步内轮廓、裁切、液面和支点。
- 同行玩法ID为judge／pope／merchant／banker／patron，富豪图片名tycoon.png。五人均可选，没有第六空席；对手仍六位随机。
- card_empty.png是选择器的缺图／空席后备，guest.png是未知顾客后备，仍有代码引用；朗姆三种图随等级变化，不能因只有一个库存池删掉等级图。
- UI文字由原生控件绘制，不烘焙进图；focus_draw_center=false只画焦点边缘。换图不要运行按钮模板导出器覆盖美术。
- 当前只有已接入的选人／顾客立绘，老酒保／店员独立演出、额外人物表情及复杂液体效果没有对应运行节点；不要新增空图占位。

## 生成与验收

```powershell
python tools/build_asset_index.py --project . --registry data/bar_assets.json --labels data/asset_index_labels.json --output docs/图片替换索引.md
```
