# 小漫特调

一款以「同行」为主题的异世界酒馆经营游戏。你接过老酒保的钥匙，在调酒、倾听和备货之间经营一间小店，结识愿意再次坐下的人，也与街上的同行展开十四晚的竞争。

当前验收版包含 **32款酒谱、14位顾客、5位同行者、6位竞争对手**。AI主要参与代码编写和图片生成；剧情、规则与素材的具体来源见[开发报告](docs/小漫特调游戏开发报告.docx)和[第三方说明](THIRD_PARTY_NOTICES.md)。

## 开始游玩

| 方式 | 启动方法 |
| --- | --- |
| Windows发行包 | 解压后运行 `小漫特调.exe`，无需安装Godot或.NET。 |
| Web试玩包 | 将解压后的整个 `web/` 目录放到HTTP／HTTPS静态站点，访问 `index.html`。不要直接双击HTML。 |
| 从源码运行 | 安装 **Godot 4.5.1标准版**，导入根目录 `project.godot`，等待资源导入后按F5。无需C#构建。 |

仓库不提交导出二进制；本地已有产物位于被Git忽略的 `exports/`。维护者可将发行包附在Release中。Web目录约67MB、ZIP约37MB；具体构建和部署方法见[构建与部署](docs/构建与部署.md)。

桌面使用Compatibility渲染器，建议1280×800或更大窗口；逻辑视口1440×900。Windows中文使用系统字体，Linux建议安装Noto Sans CJK SC；Web版自带中文字体。

## 怎样玩

1. **接过钥匙。** 点击「开始游戏」选择存档栏位。首次游玩先读开场，跟随老酒保完成六单教学；教程完成状态由各栏位共享。
2. **选择同行。** 普通经营先随机遇见一位对手，再从法官、教皇、商人、银行家和富豪中选择一位。每轮锁定同行，先在D0采购和准备，再进入第一晚。
3. **挂牌接客。** 每天选择一款主推，阅读顾客要求。正常点单不按现有库存筛选，缺料会无法服务，因此开门前要查看酒谱、采购辅料和必要等级。
4. **调酒并交谈。** 打开抽屉点瓶子量取，点击画面或按空格停止，再点壶倒入。按配方完成固体、调和、杯冰、入杯、后注和装饰；留意三轮交谈及特殊要求。量取不会在目标线自动停止，首次教程量取会等你确认读完。
5. **出品与打烊。** 点铃出品，查看收入和逐项失误；打烊后补货、升级、处理行情和竞争，再进入次日。D14最后一位顾客结束后，按公开的两项目标判定胜负。

**Esc**暂停、设置及存读档；**Tab**查看同行、对手、经营、市场和消息手账；**空格**停止量取／调和判定。设置页可调整四路音量、全屏和减少动画。Web音频需要首次点击后解锁。

| 同行者 | 核心能力 |
| --- | --- |
| 法官 | 按时完成酒水与三轮对话收益×1.3，否则×0.7。 |
| 教皇 | 每位顾客的耐心时间增加40%。 |
| 商人 | 原料采购费减少25%，基酒及器材升级费减少15%。 |
| 银行家 | 合格营业日结束后，按扣债后的现金结余计息。 |
| 富豪 | 首次以该同行挑战某位对手时，获得一次600金投资。 |

获胜后可挑战未击败对手、休整或自由经营；失败可从该轮D0重试。三位经济同行另有专属成功目标，不阻断正常对手推进。完整口径见[玩法与规则](docs/玩法与规则.md)。

## 存档

提供4个独立手动栏位、2个滚动自动档与共享教程记录。只支持v8经营档，读取旧版经营档会删除该旧文件；当前版本损坏档可尝试健康备份。接待中读档从当前顾客开头重做，恢复该单开始前的库存和资金。

游戏使用Godot的 `user://` 用户目录；Web存档位于当前站点的浏览器IndexedDB，与EXE分开。删除栏位需二次确认，不删除共享教程或设置。详情见[存档与兼容](docs/存档与兼容.md)。

## 参与开发

- 先读[文档导航](docs/README.md)，Agent和程序协作者再读[AGENTS.md](AGENTS.md)。
- 改玩法查 `data/` 和[开发指南](docs/开发指南.md)；改台词查[剧情与数据编辑](docs/剧情与数据编辑.md)；改图或音频查[美术与音频](docs/美术与音频.md)。
- 测试源码及外置案例在 `tests/`；回归选择和当前实现边界见[验收与边界](docs/验收与边界.md)。

在工程根目录运行，将 `godot` 换成已加入PATH的Godot标准版控制台程序：

```powershell
godot --headless --path . --editor --import --quit
godot --headless --path . --script tests/suites/smoke.gd
godot --headless --path . --script tests/suites/save_system.gd
```
